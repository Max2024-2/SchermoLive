# SchermoLive

File pronti da scaricare:

- [App Android](SchermoLive.apk) — APK di debug, firmato per installazioni di prova.
- [App iOS](SchermoLive.ipa) — IPA non firmato; va firmato prima dell’installazione.

Viewer: https://schermolive-2-0.onrender.com/view

Per pubblicare il server su Render, imposta Root Directory su `server`, Build Command su `npm install` e Start Command su `npm start`.
